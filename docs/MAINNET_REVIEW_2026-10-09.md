## Implemented safeguards

- Mainnet deploy now defaults to **read-only preflight**. It checks chain ID, code at dependencies, decimals, router factory, funded subscription ownership, artifact sizes, bounded settings and explicit admin/workflow-owner addresses. Broadcast requires a deliberate confirmation value. Mainnet mocks and legacy shared subgraph synchronization are rejected.
- Bootstrap signer configures contracts, then hands every listed administrative role to the requested admin and renounces bootstrap roles if distinct. Receiver ownership and vault beacon/bank ownership go to the final admin. CRE expected author is set before approval, closing the default shared-forwarder trust gap for new deployments. Owner binding still permits all workflows of that owner: use a dedicated mainnet workflow owner and secure its account.
- Deployment journal refuses blind reruns after partial success; nonce-sensitive library deployment no longer auto-retries uncertain RPC errors. Start block is captured **before** deployment and market creation, preserving dynamic data-source registration and mint history. Distinct 2/30/150 gwei VRF defaults are preserved. Receipts must succeed; proxy verification errors cannot be silently counted as verified on mainnet.
- Mainnet CRE files are generated under `deployments/arbitrum-one-cre`, with a mainnet RPC project file, separate from the retained Sepolia CRE tree. Generated workflow names use a distinct mainnet prefix; the hosted registry account still needs an isolation review before registration. The deploy does not seed liquidity, register hosted CRE workflows, start workers, promote an index or publish a frontend.
- Goldsky native release/staging/promotion and legacy sync now verify the active token's project ID **and name** before remote work. Mainnet uses a separate subgraph name. Release does not automatically promote or delete rollback versions. Promotion requires an explicit validation acknowledgement and healthy, synced indexing without reported errors. Legacy sync no longer prunes or moves prod and is testnet-only. Direct use of raw Goldsky CLI bypasses these wrappers: use the guarded scripts.
- Mainnet subgraph exporter writes a separate source tree and rewrites all source/template networks, constants, addresses and start blocks. Historical Sepolia funders and optional TipJar are excluded from a fresh mainnet. Add and verify a mainnet TipJar separately if tipping is in launch scope.
- Frontend mainnet builds fail on incomplete handoff/verification manifests, mixed-chain addresses/domains/explorers/subgraph paths, missing service keys or active launch bots. Invalid chain strings no longer silently become testnet. Sepolia development builds remain available; cutover builds use `BIRIBI_RELEASE_CHECK=1`.
- Contract reliability CI now runs the whole suite, including release checks; frontend CI tests the release env guard; Goldsky release is manual, serialized, environment-scoped and untagged. GitHub environment approval rules and branch protection require account configuration and were not changed here.
